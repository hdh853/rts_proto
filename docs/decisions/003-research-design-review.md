# 조사 후 통합 설계 검토 방식

사용자 요청: 이후 시스템은 설계자가 충분한 자료를 참고해 설계하고 사용자가 검토한다.

공식 자료 조사 → 기존 승인 규칙 확인 → 설계자가 하나의 수치/행동 규칙 선택 → 계산 및 실패 조건 검증 → 통합 문서 검토 → 승인 후 구현 → PR 순서다. 작은 수치 선택을 반복해서 사용자에게 요청하지 않는다. 새 설계는 설계자 선택과 사용자 승인을 구분한다.

승인된 설계: ../specs/007-meta-progression-system.md. 승인된 기준: ../specs/006-chests-currency-growth.md. 수치와 재현 모델은 ../design-data/에 보관한다. 사용자 “설계 승인. 다음 단계 진행할것”으로 승인 완료. 첫 구현 범위는 008-meta-foundation-implementation.md를 따른다. 배포와 자동 병합은 포함하지 않는다.
