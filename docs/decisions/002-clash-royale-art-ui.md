# 공통 기획 원칙 — Clash Royale 기반 아트·UI

상태: 사용자 확정 지시. 2026-09-13.

향후 모든 기획과 구현에서 모델링, 메인화면, 덱, 카드/유닛 상세, 강화/진화, 상자 목록/개봉, 초상화, 전투 카드 UI의 주 레퍼런스는 Clash Royale로 한다. 특정 화면에만 한정하지 않는다. 이 원칙은 향후 변경 명세에 기본 적용한다.

- 3D: 과장된 비율, 명확한 역할/종족 실루엣, 둥글고 두꺼운 형태, 재질과 입체감, 읽히는 공격/피격 동작을 목표로 한다.
- UI: 세로 모바일과 손가락 터치, 카드/아이콘 중심 정보, 명확한 버튼 계층, 하단 탭, 상태/비용/진행도 강조, 상세창에서 수치와 강화 정보를 제공한다.
- 카드: 초상화와 프레임/등급 배지/골드 비용/강화 진행도를 일관되게 구성한다. 초상화와 전투 모델은 같은 캐릭터 정체성을 공유한다.
- 상자: 슬롯 상태, 개봉 중 남은 시간, 수령 가능 여부, 보상 공개의 시각적 피드백을 명확히 한다.
- 현재 임시 모형·텍스트 중심 디버그 UI는 최종 기준으로 삼지 않는다. 대표 모델과 화면 시안을 먼저 검토하고 승인된 스타일로 확장한다.
- 레퍼런스는 화면 구성, 상호작용과 시각적 품질의 기준이다. 게임 자산은 자체 제작한다. 사용자가 정한 종족/챕터/5상자 슬롯/8장 덱/4장 손패/재화 규칙을 유지하며, 레퍼런스의 경제 수치나 업데이트를 자동으로 우리 규칙에 반영하지 않는다.

공식 참고: [Cards & Decks](https://support.supercell.com/clash-royale/en/articles/cards-and-decks-6.html), [Supercell Clash Royale](https://supercell.com/en/games/clashroyale/). 실제 제작 시 해당 화면·모형의 시각 레퍼런스를 모아 화면별/자산별 명세에 붙인다. 이 문서는 세부 시안 승인을 대체하지 않는다.
