## 직접 확인

- 연습 시작 → T3 재료 생성 → 한 건물을 누른 채 다른 같은 건물 위로 끌어 놓는다. 손을 떼기 전 원래 건물은 그대로, 복제 미리보기와 합성 후보 강조가 보인다. 놓으면 한 번만 T4로 합성된다. 기존 합성 버튼 경로도 동작한다.
- 빈 칸, 자기 자신, 적 건물, 필드 밖에 놓거나 끄는 중 손가락을 하나 더 대면 합성 취소. 필드 밖으로 나갔다 돌아온 경우에도 취소. 골드와 원래 건물 위치 유지.
- 광산에는 합성 버튼이 없고 드래그/손패 직접 합성도 안 된다. 일꾼 고용·판매·새 광산 건설은 동작한다.
- 전투 시작 시 08:00 표시. 06:00 분량이 지나도 게임이 끝나지 않으며 총 8분에 종료. 기지 파괴 시에는 더 일찍 끝날 수 있다. 일시정지 동안 시간 정지.
- 일반 전장/다리/던전에서 유닛을 30초 이상 관찰. 직진 중 뒤를 돌아보거나 주기적으로 멈칫하지 않아야 한다. 영웅이 밀집 건물 사이를 우회하는지 확인한다.
- 적이 옆으로 이동하거나 죽으면 새로운 공격 위치/목표를 향해야 한다. 정지 시 진영 기본 방향으로 갑자기 되돌아가지 않아야 한다.

## 확인된 원인과 수정

기존 0.6초 주기 경로 재탐색이 뒤쪽 격자점을 첫 목표로 잡았으며 경로점 도달 후 잔여 이동량을 버렸다. 직진 5초 재현에서 역행 8회, 짧은 이동 15회가 발생했다. 경로 유지·충돌 검사 기반 직선 연결·남은 이동량 이월 후 두 지표 모두 0회. 모델 위치는 시뮬레이션 좌표를 보간하고 회전 속도는 제한한다. 이동 판정 속도와 전투 수치를 높인 것은 아니다.

영웅 모서리 정지 회귀와 60개 밀집 배치 진단도 통과했다. 실제 단말에서의 부드러움과 드래그 입력은 빌드 후 최종 확인이 필요하다.
