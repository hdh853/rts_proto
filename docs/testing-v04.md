# v0.4 실행 및 검증

## 실행 방법

출력 폴더: `C:\Users\82102\Documents\Codex\2026-09-12\x20\outputs`

1. Unity 에디터를 닫는다. Unity Hub 로그인은 유지한다.
2. Windows 키+R에 위 출력 폴더 경로를 붙여넣고 Enter를 누른다.
3. `Unity_Build_v04.cmd`를 더블클릭한다. `.ps1` 파일은 직접 실행하지 않는다.
4. Windows 빌드 → 게임 화면 자동 저장(약 60초) → Android 빌드 순서로 진행한다. 빌드는 10초 간격으로 상태를 표시한다. 자동 저장 중에는 게임을 조작하지 않는다.
5. `SUCCESS`를 확인한다. 오류 시 마지막 출력만 전달하면 같은 작업 폴더의 로그를 조사할 수 있다.

Unity 라이선스 통신이 사용자 실행 환경에서만 성공한 이력이 있어 사용자 계정 실행이 필요하다. APK는 성공 후 `outputs\BackpackRTS-0.4.0.apk`, 비교 화면은 `outputs\v04-screens`에 생성된다. 빌드 전에는 이 파일들이 없거나 이전 결과일 수 있다.

Windows 수동 실행: `C:\Users\82102\Documents\Codex\2026-09-12\x20\BackpackRTS\Builds\Windows\BackpackRTS.exe`. Android는 APK를 휴대폰으로 복사하여 연다. 기존 설치와 서명이 같으면 업데이트되며, 충돌로 삭제해야 한다면 로컬 성장 저장도 지워진다.
