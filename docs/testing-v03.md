# v0.3 검증 안내

기준 명세: `docs/specs/003-placement-decks-projectiles.md`. 사용자가 명세 수정 후 즉시 작업을 승인했다.

## 현재 결과

전체 C# 정적 컴파일 성공. 실제 전투 코드를 사용하는 독립 실행 검사 51개 통과. Unity 내 저장 검사 3개를 포함한 54개 검사 통과. Windows 및 Android 개발 빌드 성공. 메인·덱·유효/무효 배치·전장·던전·T4 화면 캡처 확인. Android APK의 버전0.3.0·최소API26·대상API35·ARM64 설정을 확인했다. Android 실제 기기 터치·성능은 미검증이며 빌드 성공과 구분한다.

## v0.3 수동 검증

1. 메인 화면 아래 **덱** 탭. 생산 건물 → 기능 건물 → 마법 순서의 보유 카드 목록을 스크롤한다. 현재 선택된 슬롯 또는 목록의 제외 버튼으로 한 장을 빼면 출전 불가. 다른 카드로 총 8장이 되면 출전 가능. 종족을 바꾸면 해당 종족 카드와 공용 카드만 보여야 한다. 기존 4장 저장은 공용 카드로 8장까지 보완한다.
2. 메인 탭에서 챕터1의 클리어 수와 보상 상태를 확인한다. 보상은 현재 승리 시 자동 지급하므로 대기 보상은 없다고 표시한다. 평야 **연습**으로 시작한다.
3. 손패 병영 탭 → 필드를 누르고 유지. 반투명 모형이 따라오고 건설 가능하면 초록, 적/중립/겹치는 위치는 빨강이어야 한다. 손을 누른 상태에서는 돈이 빠지거나 건물이 생기면 안 된다. 초록에서 손을 떼면 딱 한 번 건설비가 빠진다.
4. 같은 과정을 빨간 위치에서 끝낸다. 카드·골드 유지. 필드 바깥까지 끌었다가 다시 들어와 떼도 이번 제스처는 취소된다. 새 카드 선택부터 다시 시작한다. 마법도 같은 조작이다. PC는 마우스 누름·이동·해제로 시험한다.
5. 아군·중립·적 구역 사이에 희미한 붉은 점선이 보이는지 확인한다. 10×24 전장 중 아군 건설 구역은 아래10줄이다. 인접한 병영을 여러 개 놓고 시각적으로 작은 건물 사이 통로를 따라 유닛이 앞으로 생성·이동하는지 확인한다.
6. 1칸 금광을 비어 있는 아군 금색 자원 타일에 놓는다. 4G 결제 확인. 금광 선택 후 **일꾼 +**를 눌러 6명까지만 구매되고 아래6개 표시가 채워지는지 확인한다. 모든 아군 금광 자리에 건설하면 손패에 금광이 남거나 새로 들어오지 않아야 한다. 하나를 판매하면 금광 카드가 다시 뽑힐 수 있다. 일꾼 합계7명 이상 금광끼리 합성은 거절된다.
7. 손패를 반복 사용·교체하며 같은 종류가 동시에 두 장 나타나지 않는지 확인한다. 같은 병영 카드는 사용 후 다시 뽑을 수 있으므로 합성은 가능하다.
8. 덱에 울타리·화살/석궁/마법타워를 편성한다. 울타리는 체력이 높고 공격/생산하지 않는다. 타워는 제자리에서 공격한다. 모두 같은 종류·티어끼리 합성한다. T4 선택창 길게 누르기/짧게 선택도 확인한다.
9. 전투 격려는 아군 병력 주변, 채굴 가속은 완성된 아군 금광, 화염 폭발은 적 주변에 사용한다. 대상 없는 곳에서는 사용되지 않는다. 채굴 가속은 일꾼 수입만 10초간 두 배, 전투 격려는 6초간 공격속도 강화, 화염 폭발은 반경1.5에90피해. 마법 사용 후 지도에 건물이 남지 않는다.
10. 원거리 유닛/타워의 발사체가 날아가고 피격 순간 HP가 줄어드는지 확인한다. 직선탄은 첫 적, 석궁탄은 최대2명, 폭발탄은 지점에 도착해 범위 피해를 준다. 원래 목표가 죽어도 탄이 즉시 사라지지 않아야 한다. 일시정지하면 투사체와 피해도 멈춰야 한다.
11. 적을 인식했으나 사거리가 닿지 않는 근접 유닛이 다가가 공격하는지 확인한다. 두 다리와 인접 건물 통로도 함께 시험한다. 던전·영웅·영구 성장은 v0.2 안내의 검증을 반복한다.

## 재빌드와 로그

이 PC에서는 출력 폴더 `Unity_Build_v03.cmd` 실행. Windows → 화면 자동 캡처 → Android 순서이며 진행 상태를 10초마다 표시한다. 로그는 `work/v03-Win64.log`, `work/v03-player.log`, `work/v03-Android.log`, 화면은 `work/v03-captures`다. 성공하면 출력 폴더에 `BackpackRTS-0.3.0.apk`를 복사한다.

Android 설치는 휴대전화에서 APK 열기 또는 `adb install -r BackpackRTS-0.3.0.apk`. Android 8.0 이상 ARM64 대상. 기존과 앱 ID/개발 서명이 같으면 업데이트 설치로 저장을 유지한다. 업데이트가 서명 오류로 거절되면 임의로 기존 앱을 삭제하지 말고 먼저 오류를 보고한다.

## 구현 경계

유닛마다 데이터에서 공격·감지 거리와 탄종/속도를 바꿀 수 있다. 건물의 정수 점유 칸은 다른 건물이 침범할 수 없지만, 실제 충돌과 모델은 셀 내부0.56칸으로 작게 표현한다. 통로에서 아군끼리 완전히 막히지 않도록 부드러운 겹침을 허용한다. 좁은 통로에서도 대규모 병력의 완벽한 개별 회피나 밀집 연출을 보장하는 군중 시뮬레이터는 아니다.

마법은 위치를 선택해 사용하는 즉시 효과이며 공격 투사체와 구분한다. 화염 폭발 피해는 다음 고정 전투 틱(최대약50ms)에 반영된다. 종족 밸런스 수치는 아직 가설이며, 이번 변경의 넓어진 면적과 8장 덱에 대한 재밸런싱은 실제 플레이 피드백이 필요하다.
