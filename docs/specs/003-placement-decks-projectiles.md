# v0.3 배치·8장 덱·이동·투사체

상태: 사용자 “기획안 수정 후 작업 바로 진행”으로 명세와 구현 승인. 이 문서가 001/002의 충돌 항목에 우선한다. 초기 프로토타입 이후 첫 feature 브랜치·PR로 제출하며 자동 병합하지 않는다.

## 배치 계약

카드 탭으로 선택 → 필드에 손가락을 대면 반투명 건물과 점유 타일 미리보기 → 이동 중 좌표·비용·지형·소유 구역·점유 검사 → 손을 뗄 때만 동일 검사를 다시 수행하고 성공 시 결제한다. 가능 초록/불가 빨강. 필드 밖으로 나간 제스처는 돌아와도 취소하며, 불가능 위치에서 놓아도 취소한다. 취소 시 패와 골드를 유지하고 선택을 해제한다. 도움말·일시정지·필드 전환·앱 백그라운드 진입도 미리보기와 제스처를 취소한다. PC는 마우스 누름/드래그/해제로 같은 동작. 기존 건물의 일반 이동은 여전히 불가하다. 마법도 같은 위치 선택·해제 계약을 쓴다.

## 8장 덱과 손패

출전 덱은 종족 카드 및 공용 카드 중 서로 다른 정확히 8종. 생산/기능/마법 비율 강제 없음. 손패는 4종이며 현재 손패와 중복되는 카드를 보충하지 않는다. 금광도 8장 중 한 슬롯을 차지하는 공용 기능 카드다. 금광 후보는 해당 플레이어가 건설할 수 있는 비어 있는 자원 타일 수가 1 이상일 때만 공급한다. 서로 다른 카드 규칙 때문에 손패 금광은 최대 1장이다. 마지막 자원 타일이 찼다면 손패 금광도 무료 교체 대기로 전환하고 다른 적격 카드를 보충한다. 적 구역의 금광은 아군 수량 계산에서 제외. 무료 교체 최초1회·사용 후30초·최대1회 유지.

기본 덱: 기존 생산4종 + 금광 + 화살타워 + 울타리 + 화염 폭발. 기존 4장 저장 덱은 고유 ID를 유지하면서 공용 카드로 8장까지 보완한다. 보유 카드는 프로토타입에서 해당 종족6종과 공용8종을 모두 제공한다. 리스트는 생산→기능→마법 정렬, 스크롤 지원.

## 기능 건물과 마법

금광 1×1/4G/일꾼 최대6명(모든 티어 공통), 울타리 2×1/5G/고체력·공격없음, 화살타워 1×1/8G/일반 직선탄, 석궁타워 1×1/11G/관통탄, 마법타워 1×1/14G/폭발탄. 모든 건물 T4 합성 및 선택 가능. 일꾼은 금광 아래 6개 표시로 시각화한다. 합성 인원 합이 6을 초과하면 합성을 거절해 구매한 일꾼이 소실되지 않게 한다. 기본 제공 금광1개+일꾼1명은 유지, 카드로 추가하는 금광은 항상 유료다.

마법은 합성 불가, 1회 사용 후 카드 보충. 전투 격려 5G: 반경2 내 아군 공격속도 6초 강화. 채굴 가속 4G: 선택한 아군 금광 일꾼 수입 10초간2배(중첩은 남은 시간 갱신). 화염 폭발 7G: 반경1.5 내 적에 즉시90피해. 유효 대상 없는 위치는 빨간 미리보기로 거절. 값은 JSON으로 변경 가능.

## 넓어진 전장과 이동

일반 필드 10×24, 아군 y0~9·중립 y10~13·적 y14~23. 아군 건설 영역 56→100칸(차감 전). 던전은 8×12, 아래6줄 건설. 경계에는 낮은 대비의 붉은 점선을 표시한다.

배치 점유는 정수 격자, 충돌/경로는 별도 0.25칸 격자. 각 건물 점유 셀 안의 실제 충돌 사각형을 가장자리에서0.22칸씩 줄여 인접 건물 사이0.44칸 통로를 보장한다. 유닛 충돌 반경0.08칸. 모델도 셀 내부에 맞춰 축소하고 복잡한 발자국은 셀별 모형으로 빈 셀을 침범하지 않는다. 울타리는 몸체를 통과할 수 없고 적이 우회하거나 공격하지만, 건물 간 통로 자체를 완전히 봉쇄하지는 않는다. 생산 위치는 진영 진행 방향의 건물 앞쪽 통로만 사용하며 뒤쪽으로 대체 출구를 고르지 않는다.

유닛별 공격 사거리와 더 넓은 감지 거리를 별도 데이터로 둔다. 감지했지만 공격할 수 없으면 실제 사거리·시야가 만족되는 좌표까지 경로를 탐색한다. 경로 도착 허용범위가 사거리보다 넓어 정지하는 기존 문제를 제거한다. 좁은 통로에서는 아군 유닛끼리 경로를 영구 봉쇄하지 않도록 소프트 겹침을 허용한다.

## 투사체

원거리와 타워는 발사 시 피해 없음. 실제 전투 시계에 따라 이동하는 투사체가 피격했을 때 피해를 처리한다. 모델 위치와 충돌 판정은 같은 투사체 상태를 참조한다. 발사 후 사수·원래 목표가 죽어도 유지.

- 직선탄: 발사 때 방향 확정, 경로상 처음 만나는 적에게 명중. 원래 목표가 죽어도 뒤의 적을 맞힐 수 있으며 아무도 없으면 빗나간다.
- 관통탄: 경로상 최대2개 적, 같은 적 중복 피해 불가.
- 폭발탄: 발사 당시 목표 지점까지 날아가 도착 시 현재 반경 내 적에게 광역 피해. 목표가 죽어도 지점에 도달한다.

탄종·속도·관통 수·감지 거리는 티어별 데이터로 조정한다. 같은 필드의 적 유닛/건물만 피격한다. 큰 dt에서도 이동 구간을 세분화해 관통 누락을 방지한다. 일시정지 시 이동과 피해 모두 멈춘다. 독·광역 효과는 발사 시가 아닌 명중 시 적용한다.
