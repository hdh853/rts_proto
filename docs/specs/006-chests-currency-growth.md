# 상자·재화·강화 확정 명세

상태: 아래 확정 범위는 사용자 승인 완료. 2026-09-13. 사용자 “이렇게 확정하고 다음 스텝을 안내해줘” 반영. 경제 비용·카드별 상한·영웅 세부 규칙과 최종 구현 명세는 후속 확정 대상이다. 이 승인을 미정 수치나 신규 기능의 구현 승인으로 확대하지 않는다.

공통 전제: 모델링·메인·덱·카드 상세·강화·상자·초상화 UI는 Clash Royale을 주 레퍼런스로 한다. docs/decisions/002-clash-royale-art-ui.md 참조.

## 1. 확정된 플레이 순환

시작 카드로 스토리 전투 → 상자 획득 → 개봉 → 카드/재화 획득 → 레벨 강화/등급 진화 → 다음 전투.

클리어 직후 스톤 직접 지급은 삭제하되, 스톤은 상자에서 획득하는 성장 재화로 유지한다. 전투 내 골드/소울 및 판 종료 초기화는 유지한다. 초기 카드 지급은 별도 시작 보상이다.

상자는 최대5개 소유하고 동시에1개만 개봉 작업한다. 만석 시 입장 전 안내 후 전투 가능하며 새 상자는 지급하지 않는다. 기존 상자를 자동 폐기하거나 미지급 상자를 별도 대기함에 누적하지 않는다.

## 2. 강화와 진화

| 현재 등급 | 다음 진화 전 레벨 강화 횟수 | N Lv1부터 누적 도달 레벨 |
|---|---:|---:|
| N | 3 | Lv4 |
| R | 5 | Lv9 |
| SR | 7 | Lv16 |
| SSR | 10 | Lv26 |
| UR | 최대15 | 최대Lv41 |

레벨 강화는 동일 카드와 스톤을 소비한다. 등급 진화는 종족스톤만 소비하며 동일 카드/조각은 필요하지 않다. 진화해도 누적 레벨을 유지한다. 카드별 최대 등급·레벨은 별도 설정한다. 위 누적 레벨은 N Lv1부터 시작하고 UR 최종까지 성장하는 카드의 기준이다.

전투 티어 T1~T4는 영구 레벨·등급과 별개다. 영구 레벨당 기준 체력·공격력 +2% 선형 증가를 기본으로 한다: 배율=1+0.02×(Lv-1). 사거리·이동속도·공격주기·생산주기는 자동 증가시키지 않는다. 등급 진화는 스킬 해금 중심이며 기존 T4 분기와의 조합은 개별 스킬 명세에서 정한다. 기능 건물/마법의 성장 항목도 별도 정의한다.

## 3. 상자 기본 보상

카드와 스톤은 모든 상자에서 확정 지급한다. 카드 종류는 스테이지 보상 풀에서 추첨하며 같은 카드 여러 장을 묶음으로 지급한다.

| 상자 | 개봉 시간 | 카드 총수 | 스톤 |
|---|---:|---:|---:|
| N | 5분 | 6 | 40 |
| R | 30분 | 20 | 140 |
| SR | 2시간 | 60 | 500 |
| SSR | 6시간 | 180 | 1,600 |
| UR | 12시간 | 500 | 5,000 |

묶음 예시 N2종×3장, SR3종×20장. 전체 등급별 묶음 분배·보상 풀 고정 시점·미보유 카드 최초 해금 처리는 후속 데이터 명세에 명시한다.

상자 등급과 보유 카드 영구 등급은 독립이다. SSR 상자를 얻어도 카드가 자동으로 SSR로 진화하지 않는다.

## 4. 추가 보상

| 상자 | 종족스톤 | 영웅 조각 | 영웅 완전체 |
|---|---|---|---|
| N | 없음 | 없음 | 없음 |
| R | 0.1%로1개 | 5%로1개 | 없음 |
| SR | 20%로1~3개 | 20%로2~4개 | 0.05%로1명 |
| SSR | 확정3~5개 | 50%로5~10개 | 0.5%로1명 |
| UR | 확정8~12개 | 확정15~25개 | 2%로1명 |

종족스톤/영웅 조각/완전체는 서로 독립적으로 추첨하며 같은 상자에서 함께 나올 수 있다. 영웅 조각 수집을 기본 해금 경로로, 완전체 획득을 드문 빠른 해금 경로로 둔다. 필요한 조각 수와 중복 완전체 처리는 미정이다.

## 5. 상자 등급 확률과 스테이지 원칙

기존 수치표를 기준으로 일반은 N60/R37/SR2.9/SSR0.1%, 정예는 SR90/SSR9.9/UR0.1%를 사용한다. 일반 범위 표기는 이 수치표와 일치하도록 N~SSR로 정리한다.

첫 정예는 N등급 덱으로 클리어 가능하도록 설계하고 R진화를 진입 조건으로 요구하지 않는다. 일반 상자는 일상 레벨 성장, 정예 상자는 진화 재료 수집의 역할을 맡는다. 정예 등장 주기·재도전 규칙은 다음 명세에서 확정한다.

참고 기대값: 상자별 종족스톤 획득 확률 일반0.717%, 정예28%. 천장 없는 독립 추첨 기준 첫 획득 누적 확률50% 이상은 일반97개/정예3개. 이는 획득 보장이나 완료 일수가 아니다. 천장/첫 보상 보정은 아직 도입하지 않았으며 추가할 경우 별도 승인한다.

## 6. 다음 과업 — 성장 비용과 진행 속도

1. 레벨별 동일 카드/스톤 요구량: 초반 첫 강화, N단계3회 완료, 주력 덱8장 성장에 필요한 상자 수와 함께 제안.
2. R/SR/SSR/UR 진화의 종족스톤 비용: 정예 획득량과 함께 산정하며 동일 카드 요구를 넣지 않는다.
3. 카드별 최대 성장: 초기12종 생산/공용8종의 출발 등급·최대 등급·레벨과 기능 건물/마법 성장 항목.
4. 첫 정예 위치, 이후 등장 간격, 재도전 보상/제한과 종족별 챕터 해금.
5. 영웅 조각 해금 수, 중복 완전체/조각 처리, 보유 영웅 선택과 판 내부 소울 소환 조건의 관계.
6. 상자 시작/완료/수령 상태, 획득 시 풀/종족 기록, 종료/복귀/저장 실패/중복 요청 처리.
7. 기존 테스트 저장 이전 또는 초기화 정책과 로컬 검증판/운영 서버 범위.

산출물은 비용표, 스테이지 진행표, 획득 편차를 포함한 성장 시뮬레이션이다. 가정(세션 길이/승률/상자 수령·개봉 일정/슬롯 만석)을 명시하고 한 장 집중과 덱 분산 성장 시나리오를 비교한다. 수치 검토 후 데이터·저장 → 상자 → 성장 → UI 순서로 구현 PR을 나눈다.
