# v0.5 명세: 드래그 합성·광산 합성 금지·8분 전투·연속 이동

상태: 사용자의 개선 요청에 따라 구현. 기존 선택 → 합성 버튼 → 대상 선택 흐름을 유지하면서 드래그 합성을 추가한다.

- 아군의 완성된 T1~T3 건물을 누르고 10 UI 픽셀 이상 끌면 드래그 합성을 시작한다. 반투명 복제 모형이 손가락을 따라가며 원래 건물은 제자리에 유지된다.
- 같은 종류·같은 티어·같은 필드의 완성된 아군 건물 위에서 손을 떼면 한 번만 합성한다. 빈칸·자기 자신·다른 종류·적 건물·필드 밖·다중 터치·일시정지·도움말 진입은 합성하지 않는다. 필드 밖으로 나간 드래그는 다시 들어와도 취소된다. 취소 시 골드/건물/티어는 그대로다.
- 짧은 탭은 기존 건물/유닛 정보 선택 동작을 유지한다. 필드 간 건물 이동과 빈칸 재배치는 허용하지 않는다.
- 광산은 모든 경로(버튼·드래그·손패 직접 합성·AI)에서 합성 금지. 합성 버튼과 후보 강조도 제외한다. 건설·고용·판매는 유지한다. 광산은 이 버전에서 T1 고정이다.
- 제한 시간은 데이터의 matchSeconds=480. 화면 카운트다운과 종료 판정이 같은 값을 사용한다. 기존 코드는 360초(6분)였으며 480초(8분)로 변경한다. 일시정지는 시간을 소비하지 않는다. 시간 만료 시 기존 패배 규칙 유지.
- 이동 문제 재현: 장애물 없는 던전에서 5초간 직진시 8회 역방향 이동, 15회 짧은 이동 발생. 0.6초마다 가장 가까운 격자점으로 다시 경로를 잡고, 경로점 도착 시 남은 이동량을 버리는 원인을 수정한다.
- 충돌 검사로 검증된 직선 구간을 연결하고, 이동 중 한 틱의 남은 이동량을 다음 경로점에 사용한다. 목표가 그대로면 유효한 경로를 유지한다. 목표 이동/사망/장애물 변화에는 경로를 갱신한다.
- 모델은 실제 이동 방향 또는 공격 대상 방향을 바라보며, 정지 시 마지막 방향을 유지한다. 20Hz 시뮬레이션 좌표 사이를 렌더링 프레임에서 보간하고 회전 속도를 제한한다. 충돌/피해 판정은 시뮬레이션 좌표를 사용한다.
- 검증: 기존 검사 + 드래그 성공/취소/중복 방지, 광산 모든 합성 차단, 480초 경계, 직진 역행/속도 손실, 모서리 충돌/영웅 회귀 검사. Android에서 실제 드래그·다중 터치·이동 영상을 추가 확인한다.
